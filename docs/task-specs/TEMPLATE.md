# Task Spec Template

## Title

Short, specific name for the change.

## Why

What problem are we solving, and why does it matter now?

## Scope

What is in scope for this change?
What is explicitly out of scope?

## Constraints

List architectural, security, compatibility, or delivery constraints.

## Options Considered

List the realistic implementation options and the important tradeoffs.

## Chosen Approach

State the recommended approach and why it best fits AQAMI.

## Impacted Areas

List the expected files, crates, docs, examples, or tests that will change.

## Verification Plan

List the checks and tests that should be run.

## Follow-Ups

List any intentional future work that is not part of this change.
